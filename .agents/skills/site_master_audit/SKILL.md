   - 驗證 `🤖 AI 輔助建置聲明` 標題 (`h3`) 與內文 (`p`) 的 CSS 顏色，確保文字為高對比深藍色 (如 `#1E40AF` / `#1E3A8A`)，在淺色背景下 100% 清晰可讀。
2. **[📱 安裝 APP] 彈窗**：
   - 驗證 PWA 安裝導引畫面彈窗開啟與關閉無卡頓。
3. **[🎨 風格與佈局設定] 彈窗與 4 大主題**：
