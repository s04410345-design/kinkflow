# KinkFlow 四帳號互測 Checklist

## 測試資訊

- 測試環境：正式網站或 Vercel Preview
- 測試標記：`[QA-YYYYMMDD]`
- 帳號 A：一般會員，建立論壇文章
- 帳號 B：一般會員，留言、檢舉，不是文章作者
- 帳號 C：Verified Author，建立與發布專題誌
- 帳號 D：Admin，審核檢舉、處理內容與作者申請
- 使用不同 Chrome 使用者設定檔，避免 session 混用

## 1. 登入與權限

- [ ] A 可以登入前台並看見會員發文入口
- [ ] B 可以登入前台並看見會員留言、檢舉入口
- [ ] C 可以登入前台並看見作者工作區
- [ ] D 可以登入 `/admin/login` 並進入後台
- [ ] A 直接開啟 `/admin` 會被拒絕
- [ ] B 直接開啟 `/admin` 會被拒絕
- [ ] C 直接開啟 `/admin` 會被拒絕
- [ ] D 登出後重新開啟 `/admin` 需要重新登入

## 2. 討論版基本流程

- [ ] A 建立 `[QA]` 測試主題並選擇 Mind Map 節點
- [ ] B 看得到 A 的公開主題
- [ ] B 在 A 的主題留言
- [ ] A 看得到 B 的留言
- [ ] A 可以編輯自己的主題
- [ ] B 可以編輯自己的留言
- [ ] 日期顯示正常，不出現 `Invalid Date`
- [ ] 重新整理後文章、留言和留言數仍正確

## 3. 討論版越權流程

- [ ] B 不能編輯 A 的主題
- [ ] B 不能刪除 A 的主題
- [ ] A 不能編輯 B 的留言
- [ ] A、B 都不能進入後台資料
- [ ] A、B 不能直接呼叫管理員檢舉 API
- [ ] A、B 不能直接修改別人的文章 ID 或留言 ID

## 4. 檢舉完整流程

- [ ] B 開啟 A 的主題檢舉視窗
- [ ] B 可以選擇檢舉分類
- [ ] B 可以填寫最多 2,000 字補充說明
- [ ] 空白補充說明不能送出
- [ ] B 成功送出檢舉
- [ ] B 重複檢舉同一內容會收到阻擋提示
- [ ] D 在後台看到分類、說明、日期和目標 ID
- [ ] D 可以選擇提醒、隱藏或刪除等處理動作
- [ ] D 可以填寫管理員備註
- [ ] D 將檢舉標記為已處理
- [ ] D 將另一筆檢舉標記為駁回
- [ ] 處理後狀態、處理人、處理時間正確
- [ ] A、B 看不到管理員內部備註
- [ ] 前台不再顯示被管理員刪除或隱藏的內容

## 5. 專題誌流程

- [ ] C 可以開啟作者工作區
- [ ] A、B 不能直接建立或發布專題誌
- [ ] C 建立文章草稿
- [ ] C 選擇最多 3 個 Mind Map 節點
- [ ] C 編輯標題、摘要與 Markdown
- [ ] C 開啟預覽模式
- [ ] 預覽中的危險 URL 不會被渲染
- [ ] C 編輯既有草稿時，停止輸入約 1.5 秒會自動儲存
- [ ] 自動儲存狀態會顯示「自動儲存中」和「已儲存時間」
- [ ] C 關閉編輯器後重新開啟，內容和節點仍存在
- [ ] C 發布文章
- [ ] 公開文章可以從對應 Mind Map 節點找到
- [ ] C 可以編輯自己的已發布文章
- [ ] A、B 不能編輯 C 的文章
- [ ] D 可以管理或下架 C 的文章

## 6. 大廳聊天與手機畫面

- [ ] 未登入視窗可以開啟大廳聊天抽屜
- [ ] 符合限制的訊息可以送出
- [ ] 超過 240 字會被阻擋
- [ ] 沒有 guest key 的請求會被阻擋
- [ ] 短時間大量送出會觸發速率限制
- [ ] 圖片／GIF 格式和大小限制正常
- [ ] Chrome 375×812 模擬尺寸不會被鍵盤遮住
- [ ] Chrome 390×844 模擬尺寸沒有橫向溢出

## 7. 清理與紀錄

- [ ] D 清理所有 `[QA]` 測試文章、留言、檢舉和專題
- [ ] 測試資料使用 `deleted` 或 `hidden` 軟刪除
- [ ] 公開前台重新整理後看不到測試資料
- [ ] 後台仍保留必要的處理狀態和稽核紀錄
- [ ] 在驗收紀錄填入每一項的日期、操作者、結果和備註

## 判定

- 通過：所有 P0 項目通過，沒有越權、資料外洩或測試資料殘留。
- 暫停上線：任何帳號越權、管理備註外洩、檢舉可重複濫用或資料清理失敗。
- 非阻塞：純視覺細節、效能 advisor INFO、未使用的未來功能。
